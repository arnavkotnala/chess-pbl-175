ChessVerse

An Interactive Chess Game with AI Powered Gameplay

ChessVerse is a chess application made using C and C plus plus and Raylib combining chess gameplay with intelligence. The project is about creating chess rules checking moves and building an AI opponent that uses the Minimax algorithm with Alpha Beta Pruning to pick moves.

The application also has a Hint Engine a Move Noter and changeable AI difficulty to offer a chess playing experience.

AI Implementation

ChessVerse uses the Minimax algorithm to look at moves and check different chess positions. The algorithm looks at replies from both players to decide a move.

Alpha Beta Pruning helps the search process by removing branches that do not need to be checked. This helps the AI check positions quickly.

The difficulty level is changed manually letting players choose their level of challenge.
